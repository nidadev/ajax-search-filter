# Freshdesk API Integration - AJAX Search & Ticket Viewer

This project is a CodeIgniter 3-based application that integrates with the **Freshdesk API** to fetch and display support tickets dynamically using AJAX-based search and filtering.

It demonstrates how external REST APIs can be integrated into a PHP MVC application and rendered in a user-friendly interface without page reloads.

---

## 🚀 Features

- Integration with Freshdesk REST API
- Fetch and display support tickets dynamically
- AJAX-based search and filtering (no page reload)
- Clean MVC structure using CodeIgniter 3
- Secure API request handling
- Responsive UI for ticket listing
- Error handling for API responses

---

## 🛠 Tech Stack

- CodeIgniter 3 (PHP Framework)
- PHP
- Freshdesk REST API
- AJAX (jQuery)
- MySQL (if local caching used)
- HTML / CSS / JavaScript
